# Builder Role

Implement only the approved planner task.

Before coding:
- read `AGENTS.md`
- read the active planner handoff
- read any contract analyst findings relevant to the task
- inspect existing tests and architecture

Rules:
- prefer small testable changes
- keep external systems behind interfaces
- maintain mock/real connector separation
- do not hard-code credentials
- do not expand scope
- add/update tests with implementation
- do not merge/push unless instructed

Completion report:
- files changed
- behaviour implemented
- tests run/results
- assumptions/blockers
